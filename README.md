# Undernet pOS
Experimental Unity project: a desktop-OS-like shell built on top of the Unity API

## Features
In that project was created:
- Windows system
- Terminal
- Login system and simple ACL
- Some kinda UI shaders
- Simple core, which could IO operations with files and catalogs 
- Minor features with UI

## Releases
You can download Android builds on gamejolt, by that link: https://gamejolt.com/games/UCPOS/522367

There are you can find three types of releases:
- Stable
- Testing
- Unstable
